```sql

  id INTEGER PRIMARY KEY AUTOINCREMENT,
  username TEXT UNIQUE NOT NULL,
  password TEXT NOT NULL,

);

CREATE TABLE posts (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  user_id INTEGER NOT NULL,
  content TEXT NOT NULL,

  created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
```

- **Node.js + Express.js** — 後端 MVC 架構

**檔案：** `08.js`

```javascript

  a.push(99);
  b = [100];

console.log(listB);
```

**說明：**

### 開發過程與問題修正

**問題 1：頁面渲染異常（畫面空白或黑屏）**
- **原因：** `cart.html` 中錯誤地包含了 `index.html` 的完整程式碼，導致重複的 `<html>`、`<head>`、`<body>` 標籤
- **修正：** 清空多餘程式碼，確保每個 HTML 檔案具有獨立且標準的結構

**問題 2：靜態資源路由邏輯錯誤**
- **原因：** 使用 `req.url.startsWith("/")` 作為判斷條件且放置順序過於靠前，導致所有請求被錯誤處理
- **修正：** 遵循「精確匹配優先、通用規則置後」原則，調整路由順序

**修正後的路由順序：**
1. 精確路徑：`/`（首頁）、`/index.html`、`/cart.html`
2. 特定目錄：`/images/*`
3. 通用資源：`.css`、`.js`（透過副檔名判斷）
4. 最後防線：404 頁面

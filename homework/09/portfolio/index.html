JS 進階核心邏輯

作業六：JS 進階邏輯與高階函數修煉 (10題解全收錄)

作業題目：寫出 10 題有關 JavaScript 函數與參數的練習解答。深入函數式程式設計（Functional Programming）與記憶體配置核心觀念。

完整 10 題解原始碼展示

第 1 題：Callback 基礎解耦應用 (mathTool)

將計算邏輯（相加、相減）抽離成匿名函數傳入，實作邏輯分離。

function mathTool(num1, num2, action) {
    return action(num1, num2);
}
console.log(mathTool(10, 5, (a, b) => a + b)); // 輸出 15
console.log(mathTool(10, 5, (a, b) => a - b)); // 輸出 5

第 2 題：立即執行函數 (IIFE) 與範疇鎖定

建立獨立的私有範疇，鎖定內部關鍵變數防全域污染。

(function() {
    let localVar = "私有變數";
    console.log("IIFE 自動執行，內部變數：" + localVar);
})();

第 3 題：箭頭函數與陣列批量轉換 (map)

不污染或破壞原始陣列，批量映射回傳全新陣列（打 8 折）。

const prices = [100, 200, 300];
const discounted = prices.map(p => p * 0.8);
console.log(discounted); // [80, 160, 240]

第 4 題：陣列與物件引數的「破壞性修改」特性

探討傳址（Pass by Reference）特性。在函數內操作 arr.pop() 會直接改動到外層陣列的記憶體實體。

function modifyArr(arr) {
    arr.pop();
}
let myArr = [1, 2, 3];
modifyArr(myArr);
console.log(myArr); // [1, 2] （外層被破壞了）

第 5 題：函數回傳函數 (Higher-Order Function) 高階閉包

運用閉包鎖定外層引數倍率，動態生成客製化乘法器。

const multiplier = (factor) => (n) => n * factor;
const double = multiplier(2);
console.log(double(10)); // 20
const triple = multiplier(3);
console.log(triple(10)); // 30

第 6 題：手寫 Callback 條件篩選器 (myFilter)

手動實作 filter 核心邏輯，依據 callback(item) 的布林值結果決定留存。

function myFilter(array, callback) {
    let result = [];
    for(let item of array) {
        if(callback(item)) result.push(item);
    }
    return result;
}
console.log(myFilter([1,2,3,4], n => n % 2 === 0)); // [2, 4]

第 7 題：利用高階箭頭函數處理多層物件陣列

過濾出陣列物件中符合條件的特定資料群（如年齡大於等於 18 歲）。

const users = [{name:"A", age:15}, {name:"B", age:20}];
const adults = users.filter(user => user.age >= 18);
console.log(adults); // [{name:"B", age:20}]

第 8 題：記憶體指標傳參陷阱：重新賦值 vs 原位修改

深入探討：obj.score 是改動原指標記憶體（外層變更）；而重新賦值是將內部參考導向新位址（外層不變）。

function test(obj) {
    obj.score = 90;   // 修改屬性 (外層會變)
    obj = { score: 100 }; // 重新賦值 (外層不變)
}

第 9 題：非同步延遲執行的 Callback 控制

使用 setTimeout 來達成非同步時間差調用，結合陣列方法串接字串。

setTimeout(() => {
    console.log(["Task", "Completed"].join(" "));
}, 2000);

第 10 題：綜合實戰應用：購物車總價與折扣回呼

將購物車陣列數字進行加總累計後，動態傳入指定的折扣回呼函數中算出最終價。

function calculateTotal(cart, discountFunc) {
    let total = cart.reduce((sum, price) => sum + price, 0);
    return discountFunc(total);
}
console.log(calculateTotal([100, 200], total => total - 50)); // 250

完整 10 題解原始碼展示

第 3 題：文章陣列遍歷與網頁 HTML 字串拼接

const params = { id: "5" };

第 5 題：實作非同步「錯誤優先」回呼函數 (Error-First Callback)

Node.js 核心工業標準慣例，第一個參數放 err，第二個參數才安全丟回資料。

function fetchData(id, callback) {
    if (id < 0) {
        return callback(new Error("ID不合法"), null);
    }
    const fakeData = { id: id, status: "success" };
    callback(null, fakeData);
}

第 6 題：JSON 字串反序列化解析與防錯

使用 JSON.parse(jsonStr) 將資料庫或 API 抓回的純文字轉回可操作的 JS 物件。

const jsonStr = '{"title": "Nodejs", "id": 1}';
const obj = JSON.parse(jsonStr);
console.log(obj.title); // Nodejs

第 7 題：模擬 SQL 資料庫查詢行為 (Simulating Database Query)

模仿 sqlite3 套件的 db.get(sql, params, callback) API，讓學生明白非同步完成後回呼函數如何承接內部查到的 row 資料。

function fakeGet(sql, params, callback) {
    setTimeout(() => {
        const fakeRow = { id: params[0], title: "資料庫回傳的文章" };
        callback(null, fakeRow);
    }, 500);
}

第 8 題：樣板字串與三元運算子的條件式渲染

在 HTML 範本中利用短路或三元運算子，動態渲染使用者登入狀態。

const renderHeader = (user) => {
    return `<h1>歡迎, ${user ? user.name : "訪客"}</h1>`;
};

第 9 題：文章字串切片與前台長度預覽 (slice)

利用 str.slice(0, 10) + "..." 限制字數，實作部落格首頁的文章大綱摘要。

const content = "這是一篇非常長長長的文章內容描述...";
const summary = content.length > 10 ? content.slice(0, 10) + "..." : content;
console.log(summary);

第 10 題：後端路由的錯誤優先攔截與提前回傳中斷

理解後端代碼中隨處可見的 if (err) return callback(err); 機制，防系統因後續讀取 undefined 而崩潰。

function checkAdmin(user, callback) {
    if (!user || user.role !== "admin") {
        return callback("權限不足，拒絕訪問"); // 提前 return 中斷
    }
    callback(null, "驗證通過");
}

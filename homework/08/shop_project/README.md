# 專案報告

## 專案名稱
Node.js 基礎購物車網站與靜態伺服器實作

---

## 一、專案目標
專案目標為使用 Node.js 建立一個簡易靜態網站伺服器，並實作購物車功能頁面，讓網站能正確載入 HTML、CSS、JavaScript 與圖片資源，理解前後端請求與路由處理的基本運作方式。

---

## 二、使用技術
- Node.js
- HTTP 模組（http）
- File System 模組（fs）
- Path 模組（path）
- HTML
- CSS
- JavaScript

---

## 三、專案架構
專案主要包含以下檔案：

- `index.html`：首頁
- `cart.html`：購物車頁面
- `style.css`：網站樣式
- `script.js`：前端互動功能
- `server.js`：Node.js 伺服器主程式

---

## 四、開發過程與問題分析

### 1. 頁面異常（畫面空白或黑屏）
在開發過程中，購物車頁面出現無法正常顯示的問題。

**原因分析：**
- `cart.html` 中錯誤包含 `index.html` 的完整 HTML 結構
- 導致 HTML 文件嵌套錯誤
- 瀏覽器解析失敗，畫面無法正常渲染

---

### 2. 靜態資源路由錯誤
在 `server.js` 中出現路由處理錯誤，導致資源載入異常。

**問題點：**
- `/cart.html` 被錯誤判定為圖片請求
- `req.url.startsWith("/")` 放置順序過前
- 導致所有請求被圖片處理邏輯攔截

---

## 五、問題修正方式

### 1. 修正 HTML 結構
- 清空 `cart.html` 中多餘或重複的 HTML
- 確保每個 HTML 檔案具有獨立且完整的結構

---

### 2. 修正 server.js 路由順序

調整路由處理順序如下：

1. 首頁 `/` 或 `/index.html`
2. `/cart.html`
3. CSS / JavaScript 檔案
4. 圖片資源（最後處理）

**核心原則：**
- 精確路由優先
- 通用路由最後執行

---

## 六、學習成果

透過本專案學習到以下重點：

- Node.js 基礎伺服器建置流程
- HTTP request 與 route matching 概念
- 靜態資源（HTML / CSS / JS / 圖片）載入方式
- 路由順序對系統運作的影響
- HTML 結構正確性對渲染的重要性

---

## 七、結論
這個專案讓我理解網站運作不僅是撰寫前端畫面，更重要的是後端如何正確處理請求與資源分配。路由順序與檔案結構的正確性，會直接影響整體網站的運作。
